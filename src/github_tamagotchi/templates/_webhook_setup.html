⚡ Enable real-time updates

By default your pet updates every few minutes via polling using a shared bot account. For instant updates on every push, PR, or issue — and so it works even for private repos the shared bot account can't read — set up a webhook:

  1. Go to your repo: Settings → Webhooks → Add webhook
  2. Set Payload URL to:
  3. Set Content type to application/json
  4. Select Just the push event (or “Let me select” → push, pull_request, issues)
  5. Click Add webhook

No secret is required. Your pet will update within seconds of each event.
